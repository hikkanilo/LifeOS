# LifeOS 1.1.0

LifeOS 1.1 makes the dashboard easier to personalize and more reliable after a Windows restart.

## Что нового

- Четыре темы оформления: «Фиолетовая ночь», «Графит», «Океан» и «Розовый кварц».
- Тема сохраняется локально и применяется сразу из раздела «Настройки».
- Исправлен импорт журнала Windows: обычное, неожиданное и аварийное выключение теперь отображаются после следующего запуска LifeOS.
- Обновлён интерфейс до версии 1.1.
- Добавлена ссылка на исходный код: https://github.com/hikkanilo/LifeOS

## Установка

Скачайте `LifeOS_1.1.0_x64-setup.exe`, запустите установщик и откройте LifeOS из меню «Пуск». Требуется Microsoft Edge WebView2 Runtime.
