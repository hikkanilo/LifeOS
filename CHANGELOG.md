# Changelog

Notable user-facing changes are documented here. Dates use ISO 8601.

## 1.1.0 — 2026-11-15

- Added four selectable themes: Violet Night, Graphite, Ocean and Rose Quartz.
- Added persistent theme preference in local SQLite settings.
- Fixed Windows shutdown history parsing; clean, unexpected and emergency shutdown events are now imported reliably.
- Updated the visible product version to 1.1 and packaged the `LifeOS_1.1.0_x64-setup.exe` installer.
- Updated the project link to [github.com/hikkanilo/LifeOS](https://github.com/hikkanilo/LifeOS).

## Unreleased

- Added one compact Boosty support card in the sidebar with the author credit "Hikkanilo <3".
- Polished repository structure, package metadata, badges, and documentation for GitHub release.
- Added a real-data year activity calendar and broader application usage dashboard.
- Added achievement progress, rarity tiers, Windows notifications and one-time scheduled daily reports.
- Added opt-in image clipboard capture with local files, preview, restore, search, process exclusions and a configurable storage cap.
- Removed duplicate app/power history from Activity.
- Added database migrations, notification preferences and reduced-motion controls.
- Prepared bilingual project documentation, contribution guidance and Windows release automation.

## 0.1.0

- Initial local-first Windows dashboard with activity, applications, system details, Firefox title tracking, clipboard text history, tray mode and startup option.
